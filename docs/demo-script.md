# 演示视频脚本

## 1. 录制目标

本视频目标是用 3-5 分钟跑通「AI 创作者辅助生产与分发平台」主链路：

```text
登录 -> AI 创作 -> 短图文编辑 -> 审核拦截 -> 合规改写 -> 发布分发 -> 榜单详情 -> 技术证据
```

演示默认使用 `AI_PROVIDER=mock`，保证画面节奏稳定、点击路径可重复。真实模型不在视频中实时调用，只用字幕或口播说明：火山方舟 OpenAI-compatible Provider 已完成生成、审核、合规改写、质量评分四类 smoke test，结果 4/4 通过。

## 2. 录制环境

建议使用本地或临时公网体验地址录制：

```text
本地地址：http://127.0.0.1:3000
演示账号：demo@toutiao.ai / demo123456
AI Provider：mock
视口尺寸：1280 x 720 或 1280 x 900
```

自动录制脚本：

```bash
npm run demo:record
```

自动录制版本的画面字幕不显示硬编码时间码，避免实际录制耗时与字幕时间发生漂移。本页时间轴主要用于人工录制和口播节奏参考。

如果服务已经运行在其他地址：

```bash
DEMO_BASE_URL=http://127.0.0.1:3002 npm run demo:record
```

## 4. 口播精简版

如果人工录制，可以按以下口播控制节奏：

```text
大家好，这是头条 AI 创作者辅助生产与分发平台。
它的核心不是单点调用大模型，而是把创作、编辑、审核、改写、质量评分和分发解释串成一条完整链路。

演示中我使用 Mock Provider，保证现场稳定；真实火山方舟 OpenAI-compatible Provider 已完成四类 smoke test，生成、审核、合规改写、质量评分 4/4 通过。

首先进入创作者工作台，点击 AI 创作。输入主题、受众和语气，系统会结合 Prompt 和素材生成短图文草稿。
进入编辑器后，可以看到标题、摘要、正文、封面建议和 AI 配图建议。这里支持逐段确认，也支持局部重写。

接下来我在正文里加入一个风险词，点击发布并审核。系统会在发布前拦截，并给出命中的风险类别。
点击合规改写后，系统生成替代表达。再次发布，内容通过审核，进入质量评分和榜单排序。

发布后打开热点榜单，可以看到质量、热度、新鲜度和反馈共同影响排序。切换到爆文和推荐榜单时，权重会变化。
进入详情页后，系统展示排序解释和 activeRankingScore 公式，让创作者知道内容为什么这样分发。

最后补充工程证据：项目有 E2E、evals、AI 调用日志、真实模型 smoke test 和线上 LCP 记录。当前是 MVP，Mock 认证、SQLite、临时 quick tunnel 和样例集规模都是明确边界。
```

## 5. 录制验收清单

- 视频时长控制在 3-5 分钟。
- 画面覆盖登录、创作、编辑、审核、合规改写、榜单、详情页。
- 至少一次展示「审核未通过」和 `gambling: 赌博`。
- 至少一次展示「发布成功」和质量分。
- 至少一次展示热点榜单运营权重。
- 至少一次展示详情页排序解释和 `activeRankingScore`。
- 字幕或口播明确说明：默认演示使用 Mock Provider。
- 字幕或口播明确说明：真实模型 smoke test 4/4 通过。
- 视频产物保存到 `artifacts/demo-video/`，或上传后在提交文档中填写可访问链接。
