# 2026-06-11 技术留存：Step 18 演示视频字幕与后段画面修正

## 本轮目标

修复演示视频的两个观感问题：

- 视频下方字幕里的时间码与真实视频时间不匹配。
- 原视频后段字幕继续变化，但画面停留在同一个详情页位置，显得像画面不动。

## 问题原因

原录制脚本在字幕标题中硬编码了类似 `03:20`、`03:40`、`03:58` 的时间标签，但 Playwright 自动操作的真实耗时会受机器状态、页面加载和等待时间影响，最终视频只有约 3 分钟，导致字幕时间码与真实时间漂移。

此外，原脚本在详情页展示排序解释后，只连续替换技术证据和版本定位字幕，没有切换页面或滚动画面，因此后段观感像静止画面配变动字幕。

## 修复方式

更新：

```text
scripts/record-demo-video.mjs
```

修复点：

- 移除视频字幕标题里的硬编码时间码。
- 保留 `docs/demo-script.md` 的时间轴作为人工录制参考，不再让自动录制字幕显示时间。
- 详情页排序解释后，先滚动页面展示技术证据字幕，再切回 `/dashboard` 展示版本定位字幕。
- 继续使用 Mock Provider 录制主链路，避免真实模型耗时影响视频节奏。
