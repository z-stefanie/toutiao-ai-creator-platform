## 关键架构决策

- 采用 Next.js App Router + React + TypeScript 的全栈单仓库方案。
- 使用 Route Handlers 承载 MVP API，但业务逻辑沉到 `src/server/*`。
- 使用 PostgreSQL + Prisma 管理结构化数据。
- AI 能力通过 OpenAI SDK 兼容适配层接入，保留 Mock Provider 兜底。
- 使用 Zod 约束 AI 生成、审核、改写、评分的结构化输出。
- 离线草稿采用 IndexedDB + 服务端版本号同步。
- 榜单排序先采用可解释预计算公式：质量分、热度、发布时间加权。
- 进阶功能围绕主闭环增强，而不另起孤立功能线。

## 最小可展示闭环

主演示路径：

```text
登录
  -> 工作台
  -> Prompt/素材准备
  -> AI 生成图文
  -> 编辑器人工修改
  -> 草稿自动保存和恢复
  -> 发布前审核
  -> 质量评分
  -> 通过后发布
  -> 榜单展示
  -> 无限滚动
  -> 内容详情
```

违规分支：

```text
发布前审核失败
  -> 展示风险类型和命中片段
  -> 自动拦截
  -> 一键生成合规替代内容
  -> 用户确认后再次提交审核
```
